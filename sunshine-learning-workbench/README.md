# 阳光学习能量站

单文件 HTML 学习工作台，复刻自[今日头条文章](https://www.toutiao.com/article/7672266431840420358/)。

## 功能

- 顶部可改孩子姓名，显示连续打卡天数、阳光值、等级
- 左侧 8 个学科导航：语文、数学、英语、科学、道法、体育、音美、综合
- 每个学科按单元拆成任务卡片，勾选任务 +5 阳光
- 每日打卡 +20 阳光，记录连续天数
- 阳光兑换商店：动画片 60、游戏 120、外出 300
- 今日推荐自动挑出 3 项未完成任务
- 数据存浏览器本地，支持导出 / 导入 JSON
- 完全离线，双击 `index.html` 即可使用

## 使用

直接用浏览器打开 `index.html`，或本地启动服务：

```bash
python3 -m http.server 8080
# 访问 http://localhost:8080/index.html
```
